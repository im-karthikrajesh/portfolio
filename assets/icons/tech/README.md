# Technology icon sources

The monochrome technology icons in this directory are vendored locally so the
portfolio has no runtime icon dependency.

- Most icons are from Simple Icons 16.27.1, licensed under CC0 1.0.
  Source: https://github.com/simple-icons/simple-icons
- `java.svg` and `amazonwebservices.svg` are from Devicon 2.17.0, licensed
  under the MIT License.
  Source: https://github.com/devicons/devicon

Brand names and logos remain the property of their respective owners. Refer to
the source projects' legal and brand-use guidance before reusing these assets
outside this portfolio.
